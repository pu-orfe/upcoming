ORFE Upcoming

This site republishes machine-readable ORFE Upcoming Events for ingest into campus services — among them the School of Engineering events newsletter and the department pages on the Engineering site. Production and development assets are available here for external consumers, integrations, and manual inspection.

What each record contains

        JSON schema
      

      

        Both feeds are a JSON array of event objects in start-time order. Times are local Eastern
        wall clock written without a timezone suffix (2026-09-21T16:15:00), matching
        how the events are advertised.
      

      

        

          
            

              Field
              What it holds
            

          
          
            
guidStable identifier carried over from the upstream calendar.

            
startTime, endTimeLocal Eastern wall clock, YYYY-MM-DDTHH:MM:SS, no suffix.

            
titleThe talk title. Never empty — see titleSource for whether a person wrote it.

            
titleSourceenriched or ics for a real title; fallback-speaker, fallback-template or fallback-series when this pipeline had to synthesise one.

            
titleIsPlaceholdertrue for the three fallback- sources. These are the listings an editor will want to chase before publication.

            
speakerSpeaker and affiliation, as advertised.

            
seriesSeminar or colloquium series, comma-joined when an event belongs to more than one.

            
locationObject with name (building), detail (room) and a reserved id.

            
contentAbstract or description text.

            
urlRefLink to the event detail page.

            
rawEventDetailsOptional raw HTML of the detail panel, with rawExtractAbstract and rawExtractBio pulled out of it.

            
newsletterEditionNewsletter variant only: the edition the record was selected for, identified by that week’s Monday.

            
cancelled, bannerImage, itemTypeReserved fields the editorial system expects.

          
        

      

    


    

      

        

          
How the assets are produced

          Workflow runs
        

        

          

            
Production path

            

              The ICS to JSON workflow runs on main every 30 minutes, publishes the
              latest release asset, and deploys /events.json to Pages.
            

          

          

            
Development path

            

              The ICS to JSON (Development) workflow is manual. Dispatch it from a branch to overwrite
              the shared dev release and the Pages content under /dev/.
            

          

          

            
Source code

            

              The implementation, workflow definitions, and Pages templates all live in
              pu-orfe/upcoming.
